# DỰ ÁN APP IOT - ĐỒNG HỒ ĐEO TAY THEO DÕI SỨC KHOẺ NGƯỜI DÙNG

## Khởi tạo dự án 
npx @react-native-community/cli@latest init AppIOT

Thư viện đang dùng
1. prettier  
   `npm install --save-dev prettier`  
   Tạo file .prettierrc và prettierignore.

2. Eslint  
   `npm install --save-dev eslint-config-prettier`  
   tạo file .eslintrc.js  
   Format src code: `npx prettier . --write`
